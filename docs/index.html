MAILCOW REST API V2

The same backend.
For your own tools.

The interface runs on mailcow REST API v2, a separate project with an OpenAPI 3.1 specification, role-based access, and API keys for automation. Install both using the manual guide or Ansible.

On your server, explore the API at /api/v2/docs and download its specification from /api/v2/openapi.yaml. Existing integrations can continue using mailcow’s /api/v1.
