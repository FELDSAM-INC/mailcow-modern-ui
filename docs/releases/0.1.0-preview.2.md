# Community Preview 2

This preview updates **mailcow Modern UI** and **mailcow REST API v2** with security hardening,
compatible dependency updates, and matching Docker image version tags.

It remains a community prerelease. Full browser-matrix and broader acceptance sign-off are
still pending.

## Changes since Preview 1

- Restrict API model assignment to explicitly permitted fields.
- Drop Linux capabilities and prevent privilege escalation in both installed addon containers.
- Update production image packages and compatible UI dependencies while retaining the supported
  Node, TypeScript, and nginx release lines.
- Add secret, source, dependency, configuration, and container scans, plus isolated authenticated
  runtime checks. Published images include SBOM and build provenance attestations; both AMD64 and
  ARM64 candidates must pass image scans before release tags are promoted.
- Group routine Dependabot updates and document security review procedures.
- Document mailcow 2026-10 compatibility and the limits found in older schema definitions.
- Publish both Docker images under `0.1.0-preview.2`. The installer still pins immutable digests
  and verifies that the version tags resolve to those same images before this release is published.

## Install or update

Use **mailcow 2026-09a or newer**, including **2026-10**, with HTTPS, Python **3.9+**, and
Docker Compose **2.20.3+**. The accepted mailcow database schema remains `18082026_1200`.
Older releases are untested; releases through `2026-07b` fail the current schema check.
See [compatibility and schema history](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.2/docs/compatibility.md).

- [Manual installation](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.2/docs/installation.md)
- [Install or update with Ansible](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.2/docs/ansible.md)
- [Update from Preview 1, roll back, or uninstall](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.2/docs/maintenance.md)
- [Screenshot tour](https://feldsam-inc.github.io/mailcow-modern-ui/)

For an existing managed installation, fetch tags, check out `v0.1.0-preview.2`, and follow the
update guide or rerun the Ansible playbook. Preserve `modern-ui/secrets.env` and existing mailcow
backups. The saved UI URL is retained by the manual helper; Ansible applies the inventory's URL
selection. Existing hand-edited deployments are not automatically migrated.

## Validation and scope

- [API release checks passed](https://github.com/FELDSAM-INC/mailcow-rest-v2/actions/runs/40230955668),
  including the contract, supported-schema tests, static checks, and both image architectures.
- [UI quality, build, image, and publication checks passed](https://github.com/FELDSAM-INC/mailcowui-ng/actions/runs/40230957677).
  The full browser-matrix run is separate from these publication gates and remains open.
- 4,775 UI unit/component tests passed, with coverage thresholds met.
- 78 targeted browser checks passed across desktop Chromium, mobile Chromium, and mobile WebKit.
- UI build, lint, formatting, contract generation, translation, license, and configured dependency
  audit checks passed. Production npm dependencies reported no advisories at validation time;
  known advisories in optional Lighthouse development tools remain documented.
- Installer checks cover Compose integration, secrets handling, repeat runs, rollback, privilege
  restrictions, and release image identity. Release pipelines also run source and image scans.
- Live installation was previously checked on AMD64. Broader browser acceptance and an ARM64
  installation report remain welcome. Automated checks do not certify the absence of security issues.
