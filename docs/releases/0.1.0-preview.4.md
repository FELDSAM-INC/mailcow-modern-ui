# Community Preview 4

This security maintenance preview updates the REST API's Python runtime and Symfony Mime
dependency. Updating existing preview installations is recommended.

## Changes since Preview 3

- Require Python `3.14.10-r0` or newer in development and production API images. The verified
  build installs `3.14.10-r1`, addressing
  [CVE-2026-115557](https://mail.python.org/archives/list/security-announce@python.org/thread/FNAJMZV6XQYLVPABNINDMF3VF66AYLW4/).
  This also invalidates the Docker layer that retained the older Python runtime.
- Update `symfony/mime` from `8.1.7` to `8.1.10`, addressing the MIME parameter-name header
  injection advisory [CVE-2026-45070](https://github.com/advisories/GHSA-vqc8-7275-q272).
- Keep the existing security gates: dependency audits and image scans must pass before
  publication. No vulnerability exceptions were added.

There are no functional UI changes, API contract changes, or new database migrations.

## Install or update

Use **mailcow 2026-09a or newer**, including **2026-10**. The accepted database schema remains
`18082026_1200`. Older releases remain untested; see the
[compatibility notes](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.4/docs/compatibility.md).

- [Manual installation](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.4/docs/installation.md)
- [Install or update with Ansible](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.4/docs/ansible.md)
- [Update an existing installation](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.4/docs/maintenance.md)
- [Screenshot tour](https://feldsam-inc.github.io/mailcow-modern-ui/)

Fetch the release tags, check out `v0.1.0-preview.4`, and follow the update guide or rerun Ansible
with the same inventory. Preserve `modern-ui/secrets.env` and existing mailcow backups. Both
installers select the same pair of images pinned by digest. Manual activation preserves the
saved `/` or `/ng/` URL; Ansible applies the inventory's URL selection.

## Validation and known limitations

- 41 targeted Python integration tests passed with 249 assertions, covering Fail2Ban rule
  validation and quarantine templates on the updated runtime.
- 257 message, quarantine, mass-mail, and password-reset tests passed with 1,738 assertions
  after the Symfony Mime update.
- The final local API production image passed Trivy with no reported vulnerabilities.
  The locked Composer dependency audit also passed.
- The full API test suite, formatting, static analysis, and contract checks passed in
  [release CI](https://github.com/FELDSAM-INC/mailcow-rest-v2/actions/runs/40759294868).
  UI type checking, lint, unit tests, and the production build also passed in
  [release CI](https://github.com/FELDSAM-INC/mailcowui-ng/actions/runs/40759297811).
- All 34 installer tests, Ansible syntax and repeated-run fixture checks, and nginx routing
  checks passed, including preservation of legacy endpoints and switching between `/` and `/ng/`.
- Release publication requires the existing source, dependency, configuration, and image
  checks. Both image architectures are scanned before version tags are published.
- Full-repository Codex Security scans were not repeated for this dependency update, by
  maintainer decision. This release does not claim a new AI scan of its final revisions.
- The full UI end-to-end suite has known failures carried over from Preview 3. The UI has no
  functional changes in this release; full browser acceptance sign-off remains outstanding.
