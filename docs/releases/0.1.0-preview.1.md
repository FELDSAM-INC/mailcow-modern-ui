# Community Preview 1

The first public preview of **mailcow Modern UI**, an independently maintained interface
for an existing mailcow installation, powered by **mailcow REST API v2**.

This release is intended for community testing and feedback. It is a prerelease;
full browser-matrix and broader acceptance sign-off remain open.

## Included

- Responsive administrator, domain administrator, and mailbox-user interfaces.
- Domains, mailboxes, templates, aliases, resources, filters, sync jobs, and routing.
- Quarantine, queue management, containers, logs, and audit history.
- Password reset, two-factor authentication, passkeys, app passwords, and account settings.
- Light and dark themes, configurable branding, and consistent tables and filters.
- A separate REST API with an OpenAPI 3.1 contract and role-scoped API keys.
- Manual installation and Ansible using public Linux AMD64 and ARM64 images.
- Optional UI at `/`, preserving `/ng/` bookmarks and mailcow's existing endpoints.

## Install

Requires **mailcow 2026-09a**, database schema **18082026_1200**, HTTPS,
Python **3.9+**, and Docker Compose **2.20.3+** on the mailcow server.

- [Manual installation, one command at a time](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.1/docs/installation.md)
- [Install with Ansible](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.1/docs/ansible.md)
- [Screenshot tour](https://feldsam-inc.github.io/mailcow-modern-ui/)
- [Updates, rollback, and removal](https://github.com/FELDSAM-INC/mailcow-modern-ui/blob/v0.1.0-preview.1/docs/maintenance.md)

Both installers use the same immutable image digests from the attached `release.json`.
No application build or registry login is required. Sign in with existing mailcow accounts.
The default URL is `/ng/`; root mode is optional and keeps the classic UI at `/index.php`.

## Validation and scope

- [API CI passed](https://github.com/FELDSAM-INC/mailcow-rest-v2/actions/runs/40196144767).
- [UI quality, production build, container, and publication checks passed](https://github.com/FELDSAM-INC/mailcowui-ng/actions/runs/40203165890), including 4,775 unit/component tests. Full end-to-end browser sign-off is still pending.
- Manual and Ansible installation, repeat runs, key retention, and URL switching are checked
  with temporary fixtures. The release workflow checks both public image architectures and
  their source revisions before publishing.
- Ansible installation at `/` was verified on a running mailcow 2026-09a server, with mobile
  and desktop login, old `/ng/` links, API readiness, and the classic interface checked.
- Compatibility is limited to the stated mailcow schema. Live installation was checked on
  AMD64; an ARM64 installation report is welcome.

Keep a mailcow backup and preserve `modern-ui/secrets.env`. The API creates its own
`restv2_` tables; it does not migrate mailcow's upstream tables. Existing hand-edited
addon deployments are not automatically migrated by the installer.
